The left sidebar is the same on every page. It groups features into four buckets so you always know where to look.

## The four sections

- **Home** — your dashboard canvas, overview, activity feed, bookmarks.
- **Family** — All People, Memories, Tree Manager, collaborators.
- **Heritage** — Migration Map, Timeline, Temples, Relationship Path, Statistics.
- **Community** — Daily Share, suggestions, duplicate detection, sources.

Click any section header to collapse or expand it. The sidebar remembers which sections you kept open.

## Keyboard shortcuts

| Shortcut | Action |
| -------- | ------ |
| `Ctrl/Cmd+K` | Open the spotlight: jump to any person or help article. |
| `?` | Show the full keyboard shortcuts panel. |
| `Esc` | Close the current modal or overlay. |
| `Ctrl+0` | Reset canvas zoom to fit. |
| Arrow keys | Move selection between person nodes on the canvas. |
| `Enter` | Open the selected person's profile. |

## The Ctrl+K spotlight

Fastest way to jump to anything. Start typing a name and the matching person appears; press Enter to center them on the canvas. Typing "help" also surfaces help articles — useful if you forget a feature's location.

## Mobile

On phones the sidebar collapses into a hamburger menu; a bottom tab bar gives quick access to Home / Tree / Memories / Settings. Swiping right from the left edge reveals the full menu.

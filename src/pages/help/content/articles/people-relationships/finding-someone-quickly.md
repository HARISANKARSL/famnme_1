In a large tree, scrolling is slow. FamNme gives you three fast-find tools.

## Ctrl / Cmd + K spotlight

Press `Ctrl+K` (Windows / Linux) or `Cmd+K` (Mac) anywhere in the app. A centered search bar appears. Start typing a name; matches appear as you type. Press Enter to center that person on the canvas.

The spotlight also searches:

- Alternate / maiden names.
- Memory titles.
- Help articles (when on the Help Center).

## All People page (`/people`)

A flat, sortable list of every person in the current tree. Useful when you want to scan or bulk-filter.

Available filters:

- **Generation** — ancestors, descendants, specific tier.
- **Gender**.
- **Alive / deceased**.
- **Has photo / missing photo** (for tidying up).
- **Has birth date / missing birth date**.
- **Claimed / unclaimed** (has the person accepted an invite to edit themselves?).

Sort by name, birth date, or last edited.

## Canvas search bar

If you prefer not using the keyboard, the canvas has a small search icon in the top toolbar. Click it and type — the matching person's card is highlighted and centered.

## Tips for big trees

- Add photos early. The eye finds faces faster than it reads names.
- Keep birth dates populated — many filters and timelines depend on them.
- Use maiden names in the dedicated field, not in parentheses in the main name — otherwise searches for the maiden name won't find the person.
